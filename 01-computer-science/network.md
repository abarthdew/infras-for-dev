## 기초 개념
네트워크는 멀리 떨어진 컴퓨터들이 데이터를 주고받기 위한 체계다. 핵심은 데이터를 작은 단위로 나누고, 여러 장비를 거쳐 목적지까지 전달한 뒤, 다시 의미 있는 데이터로 조립하는 것이다.

```text
애플리케이션 데이터
-> TCP/UDP
-> IP
-> Ethernet/Wi-Fi
-> 물리 신호
```

가장 먼저 구분해야 할 개념은 다음과 같다.

```text
IP 주소   어느 컴퓨터로 갈지 식별
port      그 컴퓨터 안의 어느 프로그램으로 갈지 식별
TCP       신뢰성 있는 연결 기반 전송
UDP       가볍고 빠른 비연결 전송
DNS       도메인 이름을 IP 주소로 변환
HTTP      웹 요청과 응답의 형식
TLS       통신 암호화와 서버 인증
```

## 간단한 예시
브라우저에서 다음 주소에 접속한다고 하자.

```text
https://example.com
```

흐름은 대략 다음과 같다.

```text
1. DNS로 example.com의 IP 주소 조회
2. 서버 IP의 443 포트로 TCP 연결
3. TLS handshake로 암호화 통신 준비
4. HTTP 요청 전송
5. 서버 또는 리버스 프록시가 요청 처리
6. HTTP 응답 수신
7. 브라우저 렌더링
```
