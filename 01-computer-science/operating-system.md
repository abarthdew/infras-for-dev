# Operating System

## 목차
- 운영체제의 역할
- 프로세스와 스레드
- 메모리 관리
- 파일 시스템

- 동시성과 스케줄링
- I/O와 인터럽트

## 기초 개념
운영체제는 하드웨어와 프로그램 사이에서 자원을 관리하는 시스템 소프트웨어다. 사용자가 실행하는 프로그램은 CPU, 메모리, 디스크, 네트워크를 직접 마음대로 쓰지 않고 운영체제가 제공하는 규칙과 인터페이스를 통해 사용한다.

```text
애플리케이션
-> 시스템 콜
-> 운영체제 커널
-> 하드웨어
```

운영체제를 배울 때 가장 먼저 알아야 할 축은 다음과 같다.

```text
프로세스   실행 중인 프로그램
스레드     프로세스 안의 실행 흐름
메모리     프로그램이 사용하는 주소 공간과 실제 RAM 관리
파일       데이터를 저장하고 접근하는 추상화
I/O        디스크, 네트워크, 터미널 같은 입출력
스케줄링   CPU를 어떤 작업에 언제 줄지 결정하는 정책
```

## 간단한 예시
터미널에서 명령어를 실행하면 운영체제 관점에서는 프로세스가 만들어진다.

```bash
ls
```

흐름은 대략 다음과 같다.

```text
shell
-> fork로 자식 프로세스 생성
-> exec로 ls 실행 파일 실행
-> ls가 디렉토리 정보를 읽음
-> stdout으로 결과 출력
```

이 짧은 명령 하나에도 프로세스 생성, 파일 시스템 접근, 표준 출력, 커널 시스템 콜이 함께 등장한다.
