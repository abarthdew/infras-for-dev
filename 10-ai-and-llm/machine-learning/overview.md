## 기초 개념
머신러닝은 데이터에서 패턴을 학습해 예측이나 분류를 수행하는 방법이다. 문제 유형, 데이터 품질, 평가 지표 선택이 중요하다.

```text
features -> model -> prediction -> loss -> update
```

## 간단한 예시
```text
house size, location, age
-> price prediction model
-> expected price
```
