## 기초 개념
Python은 읽기 쉬운 문법과 풍부한 표준 라이브러리를 가진 동적 타입 언어다. 스크립트, 자동화, 웹, 데이터, AI 분야에서 널리 쓰인다.

```text
source.py -> Python interpreter -> 실행
```

## 간단한 예시
```python
def greet(name: str) -> str:
    return f"hello {name}"

print(greet("shin"))
```
